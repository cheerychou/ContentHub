## 项目本质一句话

- 面向企业/平台的 **AI-Native 数字内容供应链系统（A-DCSC）**，覆盖内容 存储 → 制作 → 管理 → 分发 全链路。
- 核心管理原则 **三态分离**：素材区（原子态/底片）、半成品区（编辑态/母版）、制成品区（发布态/渲染指令 + 人工定稿）。

## 核心业务概念

- **底片**：进入素材区不可再生的原始文件（RAW / 干声wav / prproj 工程 / docx 修订版）。
- **渲染指令 vs 物理存储**：纯机械缩放/转格式只存"渲染指令"，引擎按需实时生成；人工定稿才物理存储。
- **血缘关系**：素材→母版→发布件的加工流转记录；目标是对改版影响面可控可追溯。
- **AI-Native**：底片识别、智能编辑、即时渲染三层均内嵌 AI，非后挂插件。
- **通用 vs 垂直**：定位偏"垂直行业专家"，以行业元数据模板 + 数据飞轮建护城河（见 STR-BV-001 §7）。
