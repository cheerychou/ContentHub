## 项目本质一句话

- 面向企业/平台的 **AI-Native 数字内容供应链系统（A-DCSC）**，覆盖内容 存储 → 制作 → 管理 → 分发 全链路。
- 核心管理原则 **三态分离**：素材区（原子态/底片）、半成品区（编辑态/母版）、制成品区（发布态/渲染指令 + 人工定稿）。

## 核心业务概念

- **底片**：进入素材区不可再生的原始文件（RAW / 干声wav / prproj 工程 / docx 修订版）。
- **三态（内容域映射）**：源料区（信源/数据/原始素材）→ 母版区（定稿文章/成片的唯一权威版本）→ 发布态（公众号/官网/GEO 变体/口播稿/四平台封面，模板/提示词驱动派生）。
- **模板与提示词**：可复用的生成指令资产，两类：封面模板（cover_template）、文本提示词（text_prompt）；母版 × 模板/提示词 → 派生物，血缘 = 生成关系记录。
- **渲染指令 vs 物理存储**：纯机械缩放/转格式只存"渲染指令"，引擎按需实时生成；人工定稿才物理存储。
- **血缘关系**：素材→母版→发布件的加工流转记录；目标是对改版影响面可控可追溯。
- **AI-Native**：底片识别、智能编辑、即时渲染三层均内嵌 AI，非后挂插件；自动化边界见 KNW-EXP-001（创意决策不自动、规则环节先自动化）。
- **产品定位**（2026-09-04 定稿）：B2B 内容供应链，自有场景（车地带数字化门店产品 CDD3 的内容营销）先行 → CDD3 生态对接 → 独立 SaaS（见 STR-BV-001 §8）。
