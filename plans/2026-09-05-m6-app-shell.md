# M6 应用骨架与页面原型（App Shell + 四原型 + 驾驶舱）实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 建立完整应用骨架（侧边栏/上栏/底栏）与四类页面原型（列表页/详情页/表单 Dialog/数据驾驶舱），界面全面对齐 CDD3 数字化门店的 UI 体系；轻量高频表单 Dialog 化，详情面板回归浏览态。

**Architecture:** 移植 CDD3 shared-ui 的骨架与原型组件（sidebar/app-footer/standard-list-page/data-table/detail-page-layout/info-field/segment-tabs/search-form/statistic/form-section/form-footer/dialog），全部剥路由（受控 activeId+onSelect）/剥权限/不引 react-query（组件本为 props 驱动）；新增 `GET /api/meta/stats` 聚合端点供侧边栏徽标与驾驶舱；表单分层 = 轻量高频 Dialog 化（列表与详情均可触发）、低频管理操作留"更多操作"。

**Tech Stack:** 现有栈不变（Tailwind v4 + base-ui + phosphor + motion 已就位）。

## Global Constraints

- 沿用全部既有约束；**重构铁律（沿用 M3/M5）**：run() handlers/primaryTask/nextStepHint/跨资产表单重置/ZONE_TRANSITIONS 接线逐字保留，只动呈现层与 DOM 位置；Dialog 化时提交逻辑原样搬入弹窗。
- **Dialog 规范**：每个受控 Dialog 打开时重置其表单 state（防跨资产泄漏的弹窗版）；取消即丢弃；主按钮 primary、危险 destructive；Dialog 组件自 CDD3 `ui/dialog.tsx` 移植（base-ui 版）。
- **信息架构**：导航顺序 = 驾驶舱(dashboard, 新增， 默认页) → 素材库(source) → 选题策划(topic) → 内容制作(master) → 内容发布(publish) → 提示词与模板(recipes)；侧边栏菜单带数量徽标（stats）。
- **阶段状态机/primaryTask/nextStepHint 语义不变**，仅适配新容器（任务卡在详情页的一个 DetailSection 内，动作改触发 Dialog）。
- CDD3 只读；token/工具类已在本仓（space-y-form/gap-section 等 theme-bindings 已含）。
- 前端门禁 = tsc/vite build + `--no-deps` 部署 + :8080 200 + 关键 curl；后端任务 TDD。
- api 镜像重建有 playwright 网络问题（既有）——后端任务提交后用现有镜像 + `alembic upgrade` 手动应用（本计划仅 1 个只读端点，无迁移）。
